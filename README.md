# GestionBea 🚀

Aplicación web moderna y responsive para la gestión integral de tareas, notas y actividades personales/profesionales.

## ✨ Características

- 📊 **Panel de control / Dashboard**: Métricas rápidas de tareas completadas, pendientes y notas activas.
- 📋 **Gestión de Tareas**: Crea, categoriza, marca como completadas y filtra tareas por prioridad y estado.
- 📝 **Bloc de Notas**: Guarda recordatorios, apuntes e ideas rápidas con etiquetas de color.
- 💾 **Persistencia local (LocalStorage)**: Tus datos se guardan directamente en tu navegador sin depender de servidores externos.
- 🌓 **Tema Adaptativo**: Interfaz limpia, accesible y optimizada tanto para escritorio como para móviles.
- 📤 **Exportar / Importar**: Copia de seguridad en JSON para no perder nada.

## 🛠️ Tecnologías

- **HTML5** semántico
- **CSS3** moderno (Variables CSS, Flexbox, CSS Grid)
- **JavaScript (ES6+)** modular y sin dependencias pesadas

## 🚀 Cómo ejecutarlo localmente

1. Abre el archivo `index.html` en cualquier navegador web moderno (Chrome, Safari, Firefox, Edge).
2. O utiliza una extensión como *Live Server* en tu editor para ver los cambios en tiempo real.
